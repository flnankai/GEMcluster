# GEMcluster 0.1.0

- Initial package version.
- Added the arXiv reference for the companion paper:
  <https://arxiv.org/abs/2605.08995>.
- Added `gem_fit()` for semiparametric elliptical mixture clustering.
- Added Rcpp kernels for distance, radial, covariance, and median operations.
- Added `gem_select_k_gap()` and `gap_select_k()` for GAP-LSE selection of the
  number of clusters.
- Added simulation helpers for Gaussian, t, Laplace, and slash elliptical
  mixtures.
